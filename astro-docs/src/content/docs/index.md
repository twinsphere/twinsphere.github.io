This is the technical documentation of twinsphere by [conplement AG](https://www.conplement.de).

twinsphere is a software suite for creation, validation, hosting, viewing and interaction with industrial digital twins
in form of [Asset Administration Shells](https://industrialdigitaltwin.org).

Our twinsphere suite consists of multiple applications and libraries:

- [twinsphere ID](/id-overview)
- [Cloud](/cloud-documentation)
- [Studio](/studio-overview)
- [Viewer](/viewer-overview)
- [Management](/management-overview)
- [Development libraries (DevKit)](/typed-aas-metamodels-overview)
- [Validators](/validators-overview)
